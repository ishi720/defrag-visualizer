# デフラグ・ビジュアライザー

ディスクの断片化と、デフラグで並べ直す様子をブラウザで見える化するツールです。実際のディスクには触りません。
Windows 95・98 式と XP 式の 2 つの並べ方を、タブで切り替えて比べられます。

## できること

- **ランダムに断片化**：長く使ったディスクを再現します。一時ファイルが消えた跡が穴として残り、ファイルがディスク中に散らばります。
- **初期状態に戻す**：最後に「ランダムに断片化」したときの配置（使用中のファイルも含む）に戻します。同じ配置で別の方式を試すときに使います。
- **使用中をランダムに決める**：1〜2 個のファイルを使用中にします。鍵のマスはデフラグでもドラッグでも動かせません。
- **ドラッグ**：マスをつかんで別の場所へ動かせます。他のデータの上に落とすと入れ替わります。
- **速度・アニメーション**：移動の速さと、データが飛んでいくアニメーションのオン・オフを切り替えられます。

## 2 つの方式

| | 95・98式 | XP式 |
|---|---|---|
| 並べ方 | よく使う（起動回数の多い）ファイルから順に、先頭から隙間なく詰める | 断片化したファイルを、まるごと入る空き領域へ移してまとめる |
| 終わったあと | 空きは後ろに 1 か所にまとまる | 空きの隙間が残りやすい |
| 移動量 | 多い | 少ない |

## 使い方

```bash
npm install
npm run dev      # 開発サーバーを起動
npm run build    # dist/ に公開用ファイルを出力
```

`dist/` の中身はそのまま静的ホスティング（GitHub Pages、Vercel など）に置けます。

## ファイル構成

```
index.html              画面（Alpine.js のテンプレート）
src/
  main.js               Alpine.js の起動
  style.css             見た目
  defrag.js             画面の状態と操作（Alpine.js コンポーネント）。手順を 1 つずつ再生する
  disk.js               ディスクのデータ構造、断片化の生成、共通の計算
  animation.js          データが飛んでいくアニメーション（Web Animations API）
  algorithms/
    win98.js            95・98 式の手順を作る
    xp.js               XP 式の手順を作る
```
